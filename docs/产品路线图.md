# Off-table Training Companion 产品路线图

> 版本：v1.0
> 定位升级：从「离台训练小工具」→ **乒乓球认知—运动训练系统（Cognitive-Motor Training System）**
> 核心链路：**看见什么 → 判断什么 → 怎么到位 → 怎么组织身体 → 怎么把力量传到球拍 → 怎么回到下一板**

---

## 1. 愿景升级

原 MVP（反应训练 / 步法训练 / ONE CUE）不应停留在"看到信号 → 尽快点击"。真实比赛链路是：

```
观察 → 提取线索 → 预判 → 判断 → 动作选择 → 启动 → 到位并稳定
     → 组织发力 → 击球 → 还原 → 继续读取下一板
```

因此整个产品升级为 **Perception–Decision–Movement–Stroke System（感知—决策—移动—击球系统）**。随机刺激 + 方向判断 + 动作选择的训练，对选择反应与"脚步+击球"整合任务更有针对性。

---

## 2. 能力模型：六层

| 层 | 名称 | 解决的问题 | 包含内容 |
| --- | --- | --- | --- |
| L1 | 身体感知 Body Awareness | 能否感觉到身体在干什么 | 松紧、足底压力、重心、髋位置、肩/小臂张力、躯干旋转、左右关系 |
| L2 | 动作结构 Movement Structure | 能否进入正确的准备/运动框架 | 准备姿态、低重心、髋膝踝协同、转髋转躯干、上肢与躯干分离、回位 |
| L3 | 发力链 Kinetic Chain | 力量是否全身协同产生，而非局部硬抡 | 地面→下肢→骨盆→躯干→肩带→上臂→前臂→拍 |
| L4 | 反应与选择 Reaction & Decision | 刺激出现后能否快速选择正确动作 | 简单反应、选择反应、方向映射、正反手选择、长短判断 |
| L5 | 预判 Anticipation | 能否在球飞出前从对方动作获取信息 | 身体朝向、肩髋变化、拍型、挥拍方向、触球时机、拍速 |
| L6 | 实战耦合 Perception–Action Coupling | 看见的信息能否驱动真实移动与动作 | 刺激→选择→移动→稳定→模拟击球 |

> L6 是最终目的：不能"手机上判断很快，球台上站着不动"。

## 3. 核心训练方法论

### 3.1 发力链（Kinetic Chain）—— 最高优先级之一

**先纠正概念：发力 ≠ 用力。**

成人业余常见错误链："想更用力" → 肩膀变紧 → 大臂主动抡 → 前臂提前发力 → 手腕补偿 → 身体反而失去参与。这是产品必须避免的学习路径。

准确概念：

> **发力 = 力量生成 + 力量传递 + 末端加速 + 控制。**

产品统一用一句话表达：

> **近端先建立动力与方向，远端在正确时机参与并加速。**

（不是"脚结束以后髋才动、髋结束腰才动"的八步依次启动——真实运动是高度重叠的连续协调。）

**力量路径**：地面 → 下肢 → 骨盆 → 躯干 → 肩带 → 上臂 → 前臂 → 球拍。

**三个词原则**（替换"锁死—憋住—突然发力"）：

> **稳定 —— 传递 —— 加速。**

**必须纠正的绝对化误区**：

| 误区 | 正确表达 |
| --- | --- |
| 大臂完全不动 | 大臂随身体运动，**不主动抡球**（肩关节必然参与） |
| 手腕机械锁死 | 手腕**保持稳定，避免主动乱甩**（稳定优先，非零运动） |
| 躯干完全锁死 | 核心**不塌、不散，但允许协调旋转**（稳定 ≠ 僵硬） |

#### 3.1.1 正手发力链：六阶段（用户可理解版：地面 → 髋 → 躯干 → 肩臂 → 前臂 → 拍）

| 阶段 | 目标 | Cue | 常见错误 |
| --- | --- | --- | --- |
| ① Ground Connection | 力量从脚下开始（不是猛蹬腿） | 脚底有压力，不是脚尖蹦起来 | 脚跟全悬空 / 蹬很大但上身没转 / 膝盖锁死 |
| ② Hip Loading | 持拍侧髋"装进去"，承重+旋转准备 | 右髋承住身体 | 屁股大幅向右甩 |
| ③ Pelvis Rotation | 髋带动骨盆转向击球方向 | 先让胯走（纠正"手抢"关键） | 疯狂转腰 |
| ④ Trunk Transfer | 骨盆启动→躯干参与→向肩带传递 | 身体带着胳膊走 | 胳膊拖着身体走 |
| ⑤ Arm Lag | 身体先走、球拍略滞后，不主动甩手 | 身体走，手跟着 | 上肢抢先 |
| ⑥ Forearm Acceleration | 身体建立运动后，前臂后段加速 | 前面松，最后快 | 引拍一结束就疯狂收小臂 |

> 研究依据：高手正手能将机械能更有效地从躯干传至上臂（与拍速相关）；持拍侧髋轴向旋转做功、骨盆轴向旋转速度均与拍速正相关；下肢需臀肌/股四头肌/小腿明显参与。**正手是全身协调，不是"用手拉过去"。**

#### 3.1.2 反手发力链：四阶段（独立设计，不能正手镜像）

| 阶段 | 目标 | Cue |
| --- | --- | --- |
| ① Stable Base | 两脚稳、膝微屈、面向来球 | 重心别坐脚跟，别后仰 |
| ② Core Loading | 骨盆+上躯干仍参与（尤其拉球） | 身体建立基础动力 |
| ③ Elbow Platform | 肘部作为相对稳定的动作平台 | 肘部稳定，前臂向前展开 |
| ④ Forearm Acceleration | 前臂围绕肘部快速输出 | 小臂弹出去（但不是只有小臂） |

> 研究依据：反手上旋前挥阶段，手臂机械能约 65%（对上旋）/77%（对下旋）来自躯干传递——反手同样不是"前臂单独弹出去"。

#### 3.1.3 起下旋专题（正手 / 反手各一）

面对下旋，需要更大的向上运动分量，动作方向、重心、球拍轨迹都会调整。**不是"普通攻球做得更用力"。**

- **正手拉下旋（Power Chain 专题 2）**：更低准备 → 更充分下肢参与 → 向前+向上的髋躯干运动 → 更长球拍加速路径 → 后段前臂加速。
  - Cue：初级"从下面起来" / 中级"腿髋把身体送起来，手不要先抬" / 高级"向前和向上的力量一起进入球拍"。
- **反手起下旋**：腿稳 → 躯干参与 → 肘相对稳定 → 前臂向前上方运动。
  - Cue：**"不是抬胳膊，是把前臂打开。"**（纠正"用大臂把整条胳膊抬起来"）

### 3.2 张力训练（Tension Awareness）—— MVP 重要缺口

真正目标不是"全程放松"，而是 **该松的时候松，该紧的时候紧**。

- **张力等级 0～10**（0=完全软掉，10=最大用力）。练习：握拳感受 8 → 完全松到 2，重复，学会主动识别"我现在到底有多紧"。
- **Shadow Swing 张力训练**：慢速空挥，准备 2～3/10 → 加速短暂提高 → 结束回到 2～3。产品显示 **松 → 快 → 松**。
- **动作链感知模式**：屏幕依次给 Cue「脚底 → 髋 → 身体 → 手臂」，每阶段 2～3 秒极慢完成。**这是学习动作组织，不是最终击球时序**（最终是连续协调动作）。

### 3.3 意识训练进阶树（Awareness Level 1–7）

| 级 | 名称 | 内容 |
| --- | --- | --- |
| 1 | Simple Reaction | 单刺激，看到绿点点击 |
| 2 | Choice Reaction | 红=正手、蓝=反手，刺激→动作映射 |
| 3 | Direction Decision | 左/中/右 → 选择移动方向 |
| 4 | Stroke Selection | 长正手/短正手/长反手/短反手 → 选择动作 |
| 5 | Ball Classification | 真实视频判断上旋/下旋、长/短、正手/反手 |
| 6 | Pre-contact Anticipation | 对手触球**之前**暂停，判断方向/旋转 |
| 7 | Occlusion Training | 控制截断时点（见 3.4） |

### 3.4 视频遮挡预判（Temporal Occlusion）—— 核心差异化 ★

截断视频训练用户"**不等球飞出来才做判断**"。非常适合地铁通勤。

- **截断时点**：T−300ms / T−200ms / T−100ms / Contact，逐题判断方向/旋转/长短，之后播放真实球路。
- **页面**：播放 → 触球前突然黑屏 → 弹「来球方向？左/中/右」→「旋转？上旋/下旋/侧旋/不确定」→ 继续播放显示答案。

**指标（不只记"答对率"）**：

| 指标 | 含义 |
| --- | --- |
| Accuracy | 判断正确率 |
| Decision Time | 选择时间 |
| Early Cue Level | 最早可稳定判断的截断时点（如 T−100ms 正确率 82%、T−200ms 68%、T−300ms 53%） |

> Early Cue Level 才真正反映 **Anticipation Ability**。研究：有经验运动员更早形成有效信息、更有效利用触球前运动学线索预测球路。

### 3.5 视觉注意（Visual Attention）—— "看球"专题

"反应慢"往往是**看球信息获取太晚**，不是神经反应慢。

三阶段：① 只追踪球（触球→飞行→落台→触拍）→ ② 关注对方拍（拍面/拍头/挥拍方向/触球位置）→ ③ 身体+球拍（躯干/肩/臂/拍，建立整体运动学线索）。

> 文案用 **"更早找到有用信息"**，不用"眼睛一直死盯球"（高手是更有效稳定的视觉搜索策略，非更多眼动）。

### 3.6 心理模拟（Mental Rehearsal）—— 地铁模式重要内容

结构化，不能做成"想象自己打得很帅"。每一次：

```
看见什么 → 判断什么 → 第一脚怎么动 → 身体怎么稳定 → ONE CUE 是什么 → 击球后怎么还原
```

语音引导（"准备 → 正手长球"），脑中模拟完整链路。研究支持心理演练结合观察与实际训练可改善正反手表现。

### 3.7 发力训练进阶（Power Chain Level 0–7）

| 级 | 名称 | 内容 |
| --- | --- | --- |
| 0 | 身体感知 | 不挥拍：足底/髋/转体/肩臂放松 |
| 1 | 分段动作 | 极慢：脚→髋→身体→手 |
| 2 | 连续动作 | 不停顿，形成连续波动 |
| 3 | 节奏变化 | 慢→慢→快（前段建立，击球前加速） |
| 4 | 随机触发 | 无刺激准备，刺激出现完成一次空挥 |
| 5 | 方向随机 | 左/右 → 移动→稳定→挥拍 |
| 6 | 正反手随机 | FH/BH → 判断→脚步→稳定→对应动作 |
| 7 | 球路模拟 | FH/BH Topspin/Backspin → 按来球调整动作 |

## 5. ONE CUE 三类型

| 类型 | 示例 |
| --- | --- |
| Technique Cue（技术） | 身体先走，手跟上 |
| Perception Cue（意识） | 对方触球前先看拍面 |
| Movement Cue（移动） | 到位以后再挥拍 |

每周仍只设**一个 Primary Cue**；另两类可作为 Secondary Reminder，但训练中**只显示 Primary Cue**。

## 8. 分阶段 Roadmap

### Phase 0 — MVP 基础版（当前已规划，对应 `技术方案.md` M0–M5）

- **M0 工程化前提**：AI 友好闭环开发环境（统一命令 `dev/build/lint/typecheck/test/verify`、`CLAUDE.md`、Stop Hook、GitHub Actions、Playwright MCP、Claude Skills），见 `技术方案.md` §19 与 `ai-友好自动化工程要求.md`。
- 场景/时长选择、ONE CUE、训练生成器、动作库、训练执行（含时机化提示）、反应训练、步法训练、核心、周末反馈、localStorage。
- **部署**：GitHub Pages（`https://codertony.github.io/TT-Companion/`），Vite `base` + HashRouter + CI 自动发布（见 `技术方案.md` §15.2 / §19.7）。
- 目标：跑通"周末问题 → ONE CUE → 工作日训练 → 周末验证"闭环。

### Phase 1 — 感知与发力链（核心差异化，与 Reaction 同等优先级）

- 身体感知专题（L1：松紧/重心/张力/分离）
- 发力链专题（L3）：正手六阶段、反手四阶段、起下旋（正/反）
- 张力训练：0–10 等级、松→快→松、动作链感知模式
- Power Chain Level 0–3
- ONE CUE 三类型
- **发力专题界面**：人体简图 + 四个发光区域（脚/髋/躯干/手臂），当前训练段高亮，只显示 2～3 条 Cue
- 验证：成人"大臂僵/手抢"类问题是否可解释、可练

### Phase 2 — 反应与预判（认知训练）

- Awareness Level 1–7（选择反应→方向→击球选择→球分类→预判）
- **视频遮挡预判 Temporal Occlusion**（T−100/200/300ms）+ 指标 Accuracy / Decision Time / Early Cue Level
- 视觉注意专题（追球→看拍→身体+拍）
- 心理模拟 Mental Rehearsal（地铁模式结构化语音引导）
- 验证：Early Cue Level 能否随训练提升

### Phase 3 — 整合与实战耦合（Cognitive-Motor）

- 整合专题：随机来球 → 判断 → 移动 → 稳定 → 发力 → 模拟击球 → 还原
- Power Chain Level 4–7（随机触发→方向→正反手→球路模拟）
- Full Shadow Rally
- 错误→专题映射完整版
- 验证：离台"判断+移动+发力"能否迁移到周末真实击球

### Phase 4 — 姿态识别与 AI（远期）

- 摄像头/骨架检测，**先检测可测量变量**：髋/肩旋转启动时刻、肘位置、腕速度、膝髋角变化、重心横向位移、拍速峰值时间、击球前后还原时间
- AI 再解释，形成闭环：视频 → 诊断 → ONE CUE → 离台训练 → 复测
- **关键原则**：比较"**技术条件下的合理范围**"，不追求"唯一标准动作模板"（不同技术/来球/速度/旋转/落点动作都不同）

## 9. 关键设计原则（贯穿全产品）

1. **发力 = 生成 + 传递 + 末端加速 + 控制**；用"稳定—传递—加速"，不用"锁死—憋住—突然发力"。
2. **近端先建立动力，远端在正确时机参与**，不教八步依次启动。
3. **不绝对化**：大臂/手腕/躯干都不"禁止运动"，只"稳定优先、不主动乱甩"。
4. **正手 / 反手 / 起下旋分开设计**，不镜像、不"更用力"。
5. **产品最终教会用户的一句话**：
   > 更早看见、更早到位、更稳定地组织身体，在正确时间把力量传到球拍，然后快速回到下一板。
