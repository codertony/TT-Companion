## 四、备注与遗留观察（非用例判定项）

- **备注 A｜结果页文案漂移**：本次修复把结果页由 `五问：…` + `稳定性门槛：…` 改成 `五问自检：…` + 四道门槛列表。信息量变大（门槛有阈值了），但与用例文档约定的原文不再一致，建议同步更新 `docs/v3-user-test-cases.md` 附录 A 或统一文案。
- **备注 B｜配比默认值与文档不符**：编排页显示的是 `tableRatio(0.5)` 的结果（23/23/23/18/13），文档写「默认约 30%/25%/20%/15%/10%」（那是 t=0 的取值）。建议明确「默认按稳定性 0.5」或改为按用户实际稳定性取值。桌面容器实测 **448px**（`max-w-md`），文档与 CLAUDE.md 写 480px，建议对齐口径。
- **未修的体验缺口（文档风险点中仍存在）**：
  - R4：`每轮约 3–6 分钟换人` 仍是静态提示，与 5–23 分钟的段落时长矛盾；`换人` 按钮不重置计时、不计数、不跟段落联动（UC-22/24 验收标准本身不要求这些，故判定通过）。
  - R5：黄态课表变 7 段、开放球减半，页面对「为什么没有比赛段」仍无任何说明。
  - R8/R9：五问仍是二态（非规格的通过/警示/未过三态）；六指标只有占位符，无字段标签、单位说明与数值校验（`上台数 > 总数` 仍可提交）。
  - R13：编排页仍没有「今日还没 Check-in →」的引导，静默按绿态处理。
  - R15：术语表（17 条）只在编排页底部，执行页/自检页查不到。
  - R17：已选发球机时切换目标技术，提示会从「适合本层」翻转为「效果有限」，无替代路径建议。
  - R18：时长只有三档，且默认 90 分钟与「3–6 分钟换人」提示冲突。
  - R20：`buildTableSession` 红态空课表分支（`今日状态不适合训练（出现警示症状），请先休息`）在编排页按钮已提前 return 的情况下仍是死代码（红态不会走到执行页）。
- **额外发现（本次实测）**：数据页的空态判定为 `离台训练 + 专项结果 + 台上训练` 三者全空；若用户只提交过「周末验证」（无任何训练记录），数据页仍显示空态，此时看不到「迁移线索」卡片。不影响 UC-43/UC-44 判定（两者前置条件都含台上训练记录），但可留意。
