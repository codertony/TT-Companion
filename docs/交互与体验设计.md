# Off-table Training Companion 交互与体验设计

> 版本：v1.0
> 依据：`ux风格.md.txt`（35 节 UX 说明）+ `产品方案.md` + `技术方案.md` + `产品路线图.md`
> 优先级声明：**交互好用 = 最高优先级**（见 §3，高于视觉装饰）

---

## 1. 设计总纲

- 定位：面向业余乒乓球爱好者的离台训练伴侣，**不是健身 App、不是教学视频库、不是竞技管理平台**。
- 一句话：**"像专业运动科技产品一样可信，像计时器一样简单，像私人教练一样始终只提醒你当前最重要的一件事。"**
- 关键词：专业、轻量、专注、反应、数据、碎片化、高效率。
- UX 核心任务：**在尽可能低的认知负担下，让用户 2～3 次点击开始一次 1～10 分钟的有效训练。**
- 最终用户感受：**"我只有 5 分钟，也知道该练什么。"**（而非"打开后还有很多内容没学"）

### 1.1 五条 UX 判断标准（每条都必须答"是"）

1. 用户是否能在 **10 秒内**找到开始训练入口？
2. 训练时用户是否知道**当前只需要关注什么**？
3. 一次训练过程中是否存在**多余信息**？
4. 用户是否可以**在地铁等碎片场景低成本完成**？
5. 训练结果是否最终**回到周末真实打球验证**？

## 2. 设计系统（Design Tokens）

### 2.1 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `primary` | `#2563EB` | 主按钮、选中态、品牌、导航高亮 |
| `teal` | `#14B8A6` | 图表、辅助状态、部分训练类型 |
| `lime` | `#84CC16` | 反应刺激、成功状态、进步、运动能量（**禁大面积铺满**） |
| `ink` | `#1F2937` | 标题、主文字、图标 |
| `gray` | `#6B7280` | 次要说明、辅助信息、未选中态 |
| `bg` | `#F8FAFC` | 页面背景（避免纯白刺眼） |
| `card` | `#FFFFFF` | 卡片 |
| `dark-bg` | `#0F172A` | 深色训练页背景 |
| `dark-deep` | `#071B2C` | 深色训练页备选/更深层 |

荧光色（Lime）**只**用于：反应刺激、成功状态、关键状态。

### 2.2 字体

- 中文优先系统字体（无衬线）。
- 字号层级（px，字号/行高）：

| 层级 | 字号/行高 | 字重 |
| --- | --- | --- |
| 大标题 | 32/40 | Bold |
| 页面标题 | 24/32 | Semibold |
| 卡片标题 | 18/26 | — |
| 正文 | 16/24 | Regular |
| 辅助 | 14/20 | — |
| Caption | 12/16 | — |

- 原则：标题可以强、正文保持轻、数字略强化、不大量全大写、不用科技感字体。
- **数字必须 `tabular-nums`**（等宽数字），避免反应时间 `0.328s` 宽度跳动。

### 2.3 间距（8pt Grid）

基础单位 8px。常用：8 / 16 / 24 / 32 / 48。页面左右边距 16～20px；卡片内边距 16px；卡片间距 12～16px。

### 2.4 圆角与阴影

- 卡片圆角 12～16px。
- 阴影非常轻，主要通过背景色/间距/边框建立层级。避免厚重阴影。

### 2.5 深色训练模式

反应训练、步法训练、训练执行页使用**深色**，与普通浏览态形成明显"进入训练状态"的心理切换。

- 背景 `#0F172A` 或 `#071B2C`；刺激物用 Lime Green 高对比。
- 深色下文字用浅灰/白，对比度满足正文可读。

### 2.6 图标

统一**线性图标**：简洁、2px 线宽、圆角、几何感。常用：地铁/家庭/办公/反应/步法/核心/计时/数据/球拍。禁止混用风格。

### 2.7 插画

轻量扁平运动插画，蓝/青/绿。用于场景说明、步法示意、空手训练动作。涉及动作教学关键姿势时：**动作正确性 > 插画风格**。

### 2.8 动效

克制。允许：按钮轻微缩放、训练开始倒计时、成功刺激闪烁、进度环、数据趋势动画。禁止：大量粒子、彩带、强烈游戏庆祝。

## 3. 交互设计原则（最高优先级）

> 本节优先级高于一切视觉细节。任何视觉决策若与"好用"冲突，以"好用"为准。

### 3.1 可用性硬指标（验收必测）

| # | 指标 | 目标 |
| --- | --- | --- |
| U1 | 冷启动到开始训练 | ≤ 3 次点击 / ≤ 10 秒 |
| U2 | 触控目标 | ≥ 48×48px |
| U3 | 训练中单步信息 | ≤ 3 条（1 主提示 + ONE CUE 条 + 进度） |
| U4 | 误触退出 | 训练中退出需确认/防误触，可快速返回 |
| U5 | 关键操作反馈 | 即时（视觉 + 可选触觉振动） |
| U6 | 状态可见 | 随时知道"在练什么 / 还差多久 / 进度" |
| U7 | 单手拇指可达 | 高频操作在底部热区 |
| U8 | 碎片场景可用 | 地铁坐姿可单手、无声音、低幅度完成 |

### 3.2 十大交互原则

1. **一屏一任务** —— 一个页面只解决一个问题；训练状态下 **专注 > 信息完整**。
2. **开始成本极低** —— 首页 → 场景 → 时长 → 开始，不要求每次配置大量参数。
3. **可见即选择** —— 用 Segmented Control / 图标卡片，不用下拉菜单。
4. **默认推荐** —— 时长默认 3/5 分钟；场景默认上次选择；减少决策。
5. **先问"在哪"，再问"练什么"** —— 以场景而非课程为入口。
6. **一次一个 Cue** —— 训练中只提醒当前一个动作点，其余进 Backlog。
7. **即时反馈 + 可恢复** —— 每个动作都有响应；误操作可返回/撤销。
8. **状态外显** —— 进度环 + 剩余时间 + 当前动作名常驻。
9. **防误触** —— 训练中隐藏底部 Tab、退出需确认、暂停按钮足够大且独立。
10. **安静克制** —— 无鸡血文案、无多余音效、提示简短。

## 4. 信息架构（4 Tab 底部导航）

> 对齐 `ux风格.md.txt` §32：**四项**，不超过五项。

```
底部导航（4 Tab）
├── 🏠 首页      —— ONE CUE + 快速开始
├── ⚡ 训练      —— 场景/时长 → 训练执行
├── 📊 数据      —— 基础趋势（训练次数/连续天数/反应时间）
└── 👤 我的      —— Cue 管理 / 周末验证 / 设置
```

二级页面（无 TabBar）：
- 场景选择、时长选择、训练执行（深色）
- 反应训练（深色）、步法训练（深色）、音频训练（深色）
- Cue 管理、周末验证、设置

MVP 总页面控制在 **6～8 个核心页面**（首页 / 场景选择 / 训练执行 / 反应训练 / 步法训练 / 周末验证 / 数据 / 我的）。

## 5. 页面交互详细设计

### 5.1 首页（一屏看完）

信息层级（自上而下，对齐 §12）：

1. 简短欢迎语（按时间问候 + 状态，如"下午好，今天练一点吗"）
2. 本周训练完成度（进度环 + "3/7 天"）
3. **ONE CUE 大卡**（独立卡片，见下）
4. **开始训练**主按钮（全宽、蓝色实底、48～52px）
5. 今日推荐（1 条，如"3 分钟 · 地铁 · 反应"）
6. 底部导航

ONE CUE 卡片格式：

```
本周 ONE CUE
  身体先走，手不要抢        ← 大字（卡片标题或更高）
  本周所有影子训练只关注这一点  ← 辅助说明（14px gray）
```

- 无 Cue 时显示引导："先记录一个想改的问题"。
- 首页优先级：**训练 > 数据**，不铺仪表盘。

### 5.2 场景选择

- 4 张大图标卡片：地铁 / 办公室 / 家 / 球馆（球馆 → 跳周末验证）。
- 选"地铁"追加二级询问：**坐姿 / 站姿**（Segmented Control，非下拉）。
- 文案避开"燃脂/挑战/冲刺"，用"利用碎片时间，保持反应状态"。

### 5.3 时长选择

- 4 个档位大按钮：1 / 3 / 5 / 10 分钟；默认推荐 **3 / 5 分钟**（高亮标"推荐"）。
- 生成按钮固定底部，文字明确动作（如"开始地铁训练 →"），场景/时长未选全时置灰。

### 5.4 训练执行页（深色）★ 核心

结构（一屏内，专注）：

```
┌──────────────────────────┐
│ ONE CUE 提示条（常驻顶部） │   ← 当前唯一动作提醒
│ 训练名 + 进度环            │
│                          │
│   [大区：当前动作示意]     │   ← 插图/方向箭头
│                          │
│   当前提示（1 条，大字）    │   ← 时机化提示（§6）
│                          │
│   倒计时 + 暂停/跳过/结束   │
└──────────────────────────┘
```

- 单步信息 ≤ 3 条；提示一次只显示 1 条（§6.4）。
- 暂停按钮独立、足够大；"结束"需二次确认（防误触 U4）。
- 页面隐藏底部 Tab。
- 每步结束轻振动 + 提示切换。

### 5.5 反应训练页（深色）

- 中央大面积刺激区：大圆点/方向箭头/文字/数字/颜色。
- 顶部：训练名 + 当前进度；底部：本次反应时间 + 连续成功次数 + 暂停。
- **不显示历史数据、排行榜**。
- 颜色刺激用高辨识度：亮绿/蓝/黄/红，深色背景上高对比（如荧光绿刺激圆）。
- MVP 自评按钮「正确/跳过」两个大按钮（§技术方案）。

### 5.6 步法训练页（深色）

- 当前指令（大字）+ 大方向箭头。
- 动作示意：轻量人物插图（表达身体朝向/移动方向/重心位置），不用真人照片。
- 当前唯一动作提醒 ≤ 2～3 条，不展示完整技术说明。

### 5.7 音频训练页（深色）

- 锁屏/黑屏可用优先；语音短促清晰（"左/右/正手/反手"）。
- 结束后不附加鼓励语音（避免干扰节奏）。

### 5.8 周末验证页

- 只问一个问题：**本周 ONE CUE 在真实打球中有没有改善？**
- 4 档大按钮：明显改善 / 略有改善 / 无明显变化 / 感觉变差。
- 可选备注（如"正手定点明显好，但移动后仍抢手"）。
- 提交后系统反馈下一步：继续 / 降难度 / 进入下一 Cue。

### 5.9 数据页

- 回答"我有没有进步？"，不炫指标。
- 保留：周训练次数、连续训练天数、反应时间趋势、训练时长、ONE CUE 完成周期、周末验证结果。
- 图表只用**简单折线图**；禁止雷达图、大量百分比、复杂评分。
- 文案优先趋势（"平均反应 0.328s，比上周快 12%"），而非孤立"84 分"。

### 5.10 我的 / 设置

- ONE CUE 管理（当前 + Backlog + 历史）。
- 设置：刺激参数、音效、语速、数据导出/清空。
- 所有列表项触控目标 ≥ 48px，重要操作二次确认。

## 6. 训练提示系统 ★（意识 / 发力感觉 的时机化提示）

> 这是本设计最重要的新增。目标：训练中**在正确的时机**，用**一条短提示**引导用户"意识"或"发力感觉"，而非把动作说明一次性倒给用户。

### 6.1 提示类型

| 类型 | 作用 | 示例 |
| --- | --- | --- |
| `cue` | 当前 ONE CUE 提醒（关键时机重复） | "身体先走，手不要抢" |
| `instruction` | 动作指令（做什么） | "站稳，重心下沉" |
| `awareness` | 意识提示（感受什么） | "感受足底 → 地面的支撑" |
| `force` | 发力感觉（哪里发力/力量传递） | "脚蹬地 → 转腰 → 带动手" |
| `safety` | 纠正/安全 | "膝别内扣，别憋气" |
| `encourage` | 克制肯定（极少） | "保持节奏，最后一组" |

### 6.2 时机机制

- **固定时间戳**：`atSec` 相对该动作开始的时间点触发（主机制）。
- **阶段**：`start / mid / end` 映射到动作时长的前/中/后段。
- 提示**不打断动作节奏**：在慢速动作、动作间隙触发；快速/反应类动作不用时机提示（刺激驱动）。

### 6.3 展示规范

- 一次只显示 **1 条**提示，大字，位于训练页中部（§5.4）。
- 每条 ≤ 12 字（尽量动词/感受开头）。
- ONE CUE 提示条**常驻顶部**，与中部时机提示区分（顶部=本周目标，中部=当下）。
- 可选 TTS 播报提示（Audio Cue 模式下）。

### 6.4 文案规范（对齐 §30 语气）

- 专业、简短、客观；不鸡血。
- 意识/发力提示用"感受/体会"句式，不评判对错。
- 反例禁止："燃爆潜能！""今天必须更强！"
- 正例："今天保持状态"、"专注一次反应"、"本周只练这一点"。

## 10. 数据模型扩展（对应 `技术方案.md`）

```ts
export type PromptType =
  | 'cue' | 'instruction' | 'awareness' | 'force' | 'safety' | 'encourage';

export interface TimedPrompt {
  atSec: number;      // 相对该动作开始的时间点
  type: PromptType;
  text: string;       // ≤ 12 字
}

export interface Exercise {
  id: string;
  name: string;
  ability: Ability;
  scenes: Scene[];
  space: number;
  equipment: Equipment;
  durationMin: number;
  intensity: Intensity;
  cueMap: CueTag[];
  cue: string;               // 该动作的静态一句话 Cue
  timedPrompts: TimedPrompt[];  // ★ 时机化提示序列；反应类为空
  description: string;
  commonMistakes: string[];
  safety: string;
  mode?: ReactionMode;
}
```

**训练执行器改动**：`Stepper` 渲染每个 step 时，按 `timedPrompts` 的 `atSec` 排序，用 step 内计时器到点切换当前提示；顶部 ONE CUE 条独立常驻（来自 plan.cueText）。

## 12. 新专题界面交互（对应 `产品路线图.md` Phase 1–2）

### 12.1 发力链专题界面（Phase 1）

- 主视觉：**人体简图 + 四个发光区域（脚 / 髋 / 躯干 / 手臂）**，当前训练段高亮；不用复杂骨骼模型。
- 只显示 2～3 条 Cue。例：今天「髋部启动」→ 屏幕只显示"脚底保持压力 / 让髋先开始转 / 手臂保持松"。

### 12.2 张力训练界面（Phase 1）

- 0～10 张力刻度，当前目标值高亮。
- Shadow Swing 张力训练：显示「松 → 快 → 松」阶段切换。
- 动作链感知模式：依次显示「脚底 → 髋 → 身体 → 手臂」，每段 2～3 秒。

### 12.3 视频遮挡预判界面（Phase 2）

- 视频播放 → 触球前**突然黑屏** → 弹「来球方向？左/中/右」→「旋转？上旋/下旋/侧旋/不确定」→ 播放答案。
- 深色界面，与反应训练一致的"进入训练状态"心理切换。
- 结果显示 Accuracy / Decision Time / Early Cue Level。

### 12.4 心理模拟界面（Phase 2）

- 语音引导为主，界面极简（可黑屏/静态），适合锁屏、地铁。
- 结构化六步：看见 → 判断 → 第一步 → 稳定 → ONE CUE → 还原。
