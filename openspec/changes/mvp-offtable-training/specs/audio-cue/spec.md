# Spec Delta

## Purpose

通过耳机语音随机播报训练指令，使用户在通勤等无法盯屏的场景下仍能进行反应与判断训练。

## ADDED Requirements

### Requirement: 语音词库
系统 SHALL 支持播报「左 / 右 / 正手 / 反手 / 短 / 长」六个指令词，并可配置是否包含「短 / 长」落点判断。

#### Scenario: 播报指令
- **WHEN** 用户启动语音训练
- **THEN** 系统按词库随机播报指令词

### Requirement: 随机间隔
语音播报之间的间隔 SHALL 在可配置的随机范围内变化（如 2～4 秒）。

#### Scenario: 播报节奏
- **WHEN** 语音训练进行中
- **THEN** 相邻两次播报的间隔在配置范围内随机，而非固定间隔

### Requirement: 可停止
系统 SHALL 允许用户随时停止语音播报，并立即终止当前语音。

#### Scenario: 停止训练
- **WHEN** 用户点击停止
- **THEN** 系统立即取消语音合成并结束本轮训练
