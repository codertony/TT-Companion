# Proposal

## Why

成人业余球友的「大臂僵 / 手先抢 / 蹬转传不上去」表面是不同问题，底层多属同一类：近端身体没有稳定、连续地组织动力，远端手臂被迫提前接管。Phase 1 把「稳定—传递—加速」落地成可练的离台发力链与张力训练，纠正「锁死—憋住—突然发力」的错误学习路径。

## What Changes

- 新增身体感知专题（L1）：松紧、重心、张力、身体分离的慢速感知练习。
- 新增发力链专题（L3）：正手六阶段（地面连接 / 髋加载 / 骨盆旋转 / 躯干传递 / 手臂滞后 / 前臂加速）、反手四阶段、正/反手起下旋专题。
- 新增张力训练：0–10 张力等级、影子挥拍「松→快→松」、动作链感知模式。
- 新增发力训练进阶 Level 0–3（身体感知 → 分段 → 连续 → 节奏变化）。
- 新增发力专题界面：人体简图 + 四个发光区域（脚 / 髋 / 躯干 / 手臂），当前训练段高亮。

> 范围：本 change 覆盖路线图 Phase 1（感知与发力链）。Power Chain Level 4–7、视频预判、整合训练属 Phase 2 / Phase 3，见对应 change。

## Capabilities

### New Capabilities

- `body-awareness`: 身体感知练习（松紧 / 重心 / 张力 / 身体分离），不挥拍、慢速、带时机化提示。
- `kinetic-chain`: 发力链教学与练习，正手六阶段 / 反手四阶段 / 起下旋，贯彻「稳定—传递—加速」与非绝对化表达。
- `tension-awareness`: 张力意识训练，0–10 等级、松→快→松、动作链感知模式。
- `power-chain-progression`: 发力训练分级进阶（Phase 1 覆盖 Level 0–3）。
