# Spec Delta

## Purpose

把「发力 = 力量生成 + 力量传递 + 末端加速 + 控制」拆成可练的发力链阶段，用「稳定—传递—加速」替代「锁死—憋住—突然发力」，并区分正手、反手与起下旋。

## ADDED Requirements

### Requirement: 正手六阶段
系统 SHALL 提供正手发力链六阶段的分段教学与练习：地面连接、髋加载、骨盆旋转、躯干传递、手臂滞后、前臂加速。

#### Scenario: 正手发力链
- **WHEN** 用户进入正手发力链专题
- **THEN** 系统按六阶段依次提供对应的 Cue 与练习，每次只强调一个阶段

### Requirement: 反手四阶段
系统 SHALL 提供反手发力链四阶段：稳定基底、核心加载、肘部平台、前臂加速。

#### Scenario: 反手发力链
- **WHEN** 用户进入反手发力链专题
- **THEN** 系统按四阶段提供 Cue 与练习，与正手模型独立、不镜像

### Requirement: 起下旋专题
系统 SHALL 为正手与反手起下旋各提供独立专题，强调更低准备、更充分下肢参与、向前+向上的髋躯干运动、更长加速路径、后段前臂加速。

#### Scenario: 正手拉下旋
- **WHEN** 用户选择正手起下旋专题
- **THEN** 系统提供「从下面起来 / 腿髋把身体送起来 / 向前和向上的力量一起进入球拍」分级 Cue

### Requirement: 非绝对化表达
系统 SHALL 对大臂、手腕、躯干以「稳定优先、不主动乱甩 / 随身体运动」表达，SHALL NOT 使用「完全锁死」「禁止移动」等绝对化表述。

#### Scenario: 教学文案
- **WHEN** 发力链教学涉及大臂、手腕或躯干
- **THEN** 文案不出现「完全锁死 / 禁止移动 / 绝对不动」等绝对化措辞
