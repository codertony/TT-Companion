# Spec Delta

## Purpose

训练「该松的时候松、该紧的时候紧」的张力意识，纠正成人业余常见的全程 7/10 僵硬发力。

## ADDED Requirements

### Requirement: 张力等级
系统 SHALL 提供 0–10 的张力等级标尺（0 = 完全放松，10 = 最大用力），供用户感知与自评当前张力。

#### Scenario: 张力自评
- **WHEN** 用户执行张力练习
- **THEN** 系统显示 0–10 标尺，用户可感知并标记当前张力

### Requirement: 松快松节奏
影子挥拍张力训练 SHALL 展示「松 → 快 → 松」阶段：准备 2–3/10，加速阶段短暂提高，结束后回到 2–3/10。

#### Scenario: 影子挥拍张力
- **WHEN** 用户执行影子挥拍张力训练
- **THEN** 系统按「松 → 快 → 松」三阶段提示张力目标

### Requirement: 动作链感知模式
系统 SHALL 提供动作链感知模式，依次提示「脚底 → 髋 → 身体 → 手臂」，每阶段持续 2～3 秒。

#### Scenario: 动作链感知
- **WHEN** 用户进入动作链感知模式
- **THEN** 系统按顺序、每段 2～3 秒提示一个环节，而非一次性展示全部
