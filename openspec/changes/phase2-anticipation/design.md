# Design

## Context

Phase 0 已交付反应训练（点色块级）与音频提示（SpeechSynthesis）。Phase 2 在其上加入真实视频预判，不引入后端。动机见 proposal.md - Why。

## Goals / Non-Goals

**Goals:**
- 用真实乒乓球视频片段把反应训练升级为触球前预判。
- 量化 Early Cue Level，作为「预判能力」而非「答题正确率」的核心指标。

**Non-Goals:**
- 不做摄像头姿态识别（Phase 4）。
- 不引入视频托管 / 后端（视频资产作为静态资源打包）。

## Decisions

### D1：视频资产打包为静态资源，MVP 用少量内置片段
- **选择**：预置若干真实乒乓球片段（触球前动作清晰），打包进 `public/`；截断点用 `<video>` 的 currentTime 控制。
- **理由**：无后端、离线可用；片段数量后续可扩。
- **备选**：用户上传视频——MVP 复杂，放弃。

### D2：遮挡用「视频暂停 + 黑屏遮罩」，而非预裁剪多个视频
- **选择**：单视频播放到 `cutMs`（相对触球时刻）时暂停并覆盖黑屏遮罩弹出问题。
- **理由**：一个片段支持任意截断时点，无需为每个 T 值预生成视频。
- **备选**：每个时点预裁剪一个视频——冗余、占空间，放弃。

### D3：Early Cue Level = 各时点正确率曲线，而非单一分数
- **选择**：按 T−300/200/100/0 分别统计正确率，展示「最早可稳定判断的时点」。
- **理由**：真正反映预判能力，符合「趋势优先、不炫分数」原则。

### D4：心理模拟复用 Phase 0 的 audio-cue（SpeechSynthesis）
- **选择**：结构化六步用语音播报，界面极简。
- **理由**：通勤锁屏场景友好；复用既有语音能力。

## Risks / Trade-offs

- [视频版权 / 素材质量] → 先用可授权或自录片段，触球前动作清晰为最低要求。
- [触球时刻标注不精确] → 每片段预标注触球时间戳，作为 cutMs 的基准。
- [移动端 `<video>` 播放 / 后台限制] → 预判训练要求前台；锁屏场景用心理模拟（纯语音）替代。
