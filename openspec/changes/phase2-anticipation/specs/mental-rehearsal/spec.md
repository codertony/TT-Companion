# Spec Delta

## Purpose

通过结构化、语音引导的心理模拟，把「看见 → 判断 → 移动 → 稳定 → ONE CUE → 还原」的完整击球链路在脑内演练，服务于真实技能迁移。

## ADDED Requirements

### Requirement: 结构化六步
心理模拟 SHALL 按固定六步引导：看见什么、判断什么、第一脚怎么动、身体怎么稳定、当前 ONE CUE 是什么、击球后怎么还原。

#### Scenario: 一次心理模拟
- **WHEN** 用户开始心理模拟
- **THEN** 系统按六步依次引导，不跳步

### Requirement: 语音引导
心理模拟 SHALL 以语音为主引导，界面保持极简（可黑屏或静态）。

#### Scenario: 语音引导
- **WHEN** 心理模拟进行中
- **THEN** 系统通过语音逐句引导六步，界面无复杂元素

### Requirement: 来球提示
心理模拟 SHALL 支持随机给出「正手长球 / 反手下旋」等来球提示，触发用户脑内演练对应动作。

#### Scenario: 随机来球
- **WHEN** 用户开始心理模拟
- **THEN** 系统随机播报一个来球类型（如「正手长球」）作为演练起点
