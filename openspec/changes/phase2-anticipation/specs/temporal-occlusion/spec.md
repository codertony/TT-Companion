# Spec Delta

## Purpose

用视频遮挡训练用户「不等球飞出来就做判断」，并量化其最早能稳定判断的截断时点，作为预判能力的核心指标。

## ADDED Requirements

### Requirement: 遮挡问答流程
系统 SHALL 按「播放视频 → 触球前突然黑屏 → 弹出方向 / 旋转判断 → 播放答案显示真实球路」的流程进行遮挡训练。

#### Scenario: 一次遮挡问答
- **WHEN** 用户进行遮挡训练
- **THEN** 视频在触球前黑屏并弹出「来球方向？左 / 中 / 右」与「旋转？上旋 / 下旋 / 侧旋 / 不确定」，作答后继续播放

### Requirement: 指标记录
系统 SHALL 记录三个预判指标：Accuracy（判断正确率）、Decision Time（选择时间）、Early Cue Level（最早可稳定判断的截断时点）。

#### Scenario: 查看指标
- **WHEN** 用户完成一轮遮挡训练
- **THEN** 系统展示正确率、平均选择时间，以及各截断时点的正确率（如 T−100ms 82%、T−200ms 68%、T−300ms 53%）

### Requirement: 时点正确率
系统 SHALL 按截断时点分别统计正确率，以反映用户最早能稳定判断的时点。

#### Scenario: 分时点正确率
- **WHEN** 训练覆盖多个截断时点
- **THEN** 系统分别显示各时点正确率，而非仅一个总正确率
