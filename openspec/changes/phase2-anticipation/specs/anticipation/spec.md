# Spec Delta

## Purpose

训练用户在球真正飞出之前，从对方身体朝向、肩髋变化、拍型与挥拍方向中提取信息，预判来球的方向、旋转与长短。

## ADDED Requirements

### Requirement: 球分类
系统 SHALL 提供基于真实视频的来球分类判断：上旋 / 下旋、长 / 短、正手 / 反手。

#### Scenario: 球分类判断
- **WHEN** 用户进入球分类训练
- **THEN** 系统播放真实来球视频并要求判断上旋 / 下旋、长 / 短、正手 / 反手

### Requirement: 触球前预判
系统 SHALL 支持在对方触球之前暂停视频，让用户判断方向 / 旋转，暂停后再播放真实球路作为答案。

#### Scenario: 触球前暂停
- **WHEN** 用户进行预判训练
- **THEN** 视频在触球前暂停并弹出方向 / 旋转判断，用户作答后继续播放

### Requirement: 截断时点
系统 SHALL 支持在 T−300ms、T−200ms、T−100ms 及触球点四个时点截断视频。

#### Scenario: 不同截断点
- **WHEN** 用户配置截断时点
- **THEN** 系统在所选时点（如 T−100ms）黑屏并提示判断
