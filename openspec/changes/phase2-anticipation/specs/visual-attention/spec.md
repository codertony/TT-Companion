# Spec Delta

## Purpose

训练更有效的视觉搜索策略——「更早找到有用信息」，而非眼睛死盯球一个点，从而改善看球信息获取的时机。

## ADDED Requirements

### Requirement: 三阶段视觉训练
系统 SHALL 提供视觉注意三阶段训练：第一阶段只追踪球，第二阶段关注对方拍，第三阶段关注身体 + 球拍的整体运动学线索。

#### Scenario: 阶段递进
- **WHEN** 用户进入视觉注意专题
- **THEN** 系统按「只追球 → 看对方拍 → 身体 + 球拍」三阶段递进引导

### Requirement: 信息优先文案
视觉注意训练 SHALL 使用「更早找到有用信息」的引导文案，SHALL NOT 使用「眼睛一直死盯球」等僵化表述。

#### Scenario: 引导文案
- **WHEN** 系统展示视觉注意引导
- **THEN** 文案强调「更早找到有用信息」，不出现「死盯球」
