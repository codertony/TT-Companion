# Proposal

## Why

当前 TT-Companion 只覆盖「离台训练」——工作日补身体控制、意识与动作模式。但用户真正要改善的是**球台表现**，而周末有限的台上时间目前是「今天想练什么就练什么」的低效对练。`业余乒乓球训练操作系统.md` 指出：台上训练的价值不在于记住几十个套路，而在于一条明确进阶链（固定球路 → 固定移动 → 半随机 → 前三板 → 开放球路 → 比赛），以及一个能自动生成训练套路的公式。V3 引入「台上训练编排器」模块，把 App 从「离台训练工具」升级为**业余乒乓球训练操作系统**：工作日离台、周末上台，用结构化编排把有限台上时间花在高价值的「动作—步法—判断—前三板」组合上。`日常训练自我验收体系.md` 进一步指出编排器还缺另一半：给每个训练项目加**自反馈闭环**（练什么 → 只注意什么 → 怎么判断对不对 → 达到什么条件过关 → 换条件还能不能做到 → 才允许进阶），否则连续几十板只是适应固定节奏，并不代表真正学会。

## What Changes

- 新增「台上训练编排器」模块（`table-training/` 能力组），与既有离台训练并行，作为周末上球台的训练计划与执行工具。
- 建立七层进阶模型（L1 单技术 → L7 条件比赛）作为台上训练的编排骨架，每层定义「是否知道下一球 / 主要目的 / 核心训练」。
- 建立训练套路数据模型 `Drill`：目标技术、球源、规则、随机度、训练者关注点、搭档任务、升级条件、下一等级——把「谁打什么球 → 打到哪里 → 对方怎么回 → 我接下来干什么」固化为可计算资源。
- 建立训练生成公式（技术 × 落点 × 移动 × 旋转 × 随机度 × 前后板）：给定目标技术，自动生成「固定 → 两落点 → 随机 → 发抢 → 起板后固定 → 起板后随机 → 条件比赛」的进阶链。
- 建立球源适配与球搭子协议：支持球搭子（水平一般/更高）、发球机、多球三种球源；贯彻「一颗球两个人同时训练」与 8 条协议规则，低水平球搭子自动降难度。
- 建立台上训练课编排：90–120 分钟课表结构（热身 → 基本球 → 核心动作 → 固定移动 → 半随机 → 前三板 → 随机/开放 → 条件比赛）与训练配比（当前 30/25/20/15/10，随水平演进到 15/20/25/20/20）。
- 与离台系统整合：ONE CUE / limiter 决定台上练什么，周末验证闭环（离台指标 → 球台迁移），并新增入口与持久化。
- 新增「自我教练闭环」能力：五层反馈 + 五问自检「准净松顺回」+ 四道进阶门槛（稳定性/质量/延迟保持/迁移）+ Level A–G 进阶算法 + 唯一主注意点 + 3 球诊断 + 六指标记录 + 反馈递减，把「升级条件」从纯板数升级为可验证的进阶门槛。

## Capabilities

### New Capabilities

- `table-training/layer-model`: 七层进阶模型与进阶链，定义每层「是否知道下一球 / 主要目的 / 核心训练」，作为台上训练的编排骨架。
- `table-training/drill-model`: 训练套路数据模型 `Drill`（目标技术/球源/规则/随机度/训练者关注点/搭档任务/升级条件/下一等级）与训练生成公式（技术 × 落点 × 移动 × 旋转 × 随机度 × 前后板）。
- `table-training/drill-library`: L1–L7 具体球路套路内容库（单技术、固定移动、固定组合、半随机、随机、发接发/前三板、条件比赛），每条含双方任务与升级条件。
- `table-training/ball-source`: 球源适配（球搭子/发球机/多球）与球搭子协议（8 条规则 + 水平一般/更高球搭子的降难度适配）。
- `table-training/session-orchestration`: 台上训练课编排（90–120 分钟课表）与训练配比（固定动作/固定脚步/半随机/前三板/随机比赛的占比演进）。
- `table-training/integration`: 与离台训练系统整合——ONE CUE/limiter 决定台上重点、周末验证闭环、台上训练入口与数据持久化。
- `table-training/self-coaching-loop`: 自我教练闭环——五层反馈、五问自检「准净松顺回」、四道进阶门槛、Level A–G 进阶算法、唯一主注意点、3 球诊断、六指标记录、反馈递减与掌握度五层级。

### Modified Capabilities

（无——V3 为新增模块，不改动既有离台训练行为规格；离台能力规格保持不变。）

## Impact

- **领域类型**：`src/types/index.ts` 新增台上训练类型（`ProgressionLayer`、`Drill`、`BallSource`、`TableSession`、`DrillDimension` 等），与既有 `Capacity`/`AssessmentResult` 等并存，不改既有字段。
- **内容库**：新增 `src/data/tableDrills.ts`（L1–L7 球路套路种子数据），对应既有 `src/data/exercises.ts` 的离台动作库。
- **生成器**：新增 `src/domain/tableGenerator.ts` 纯函数（训练生成公式 → 进阶链），与既有 `src/lib/generator.ts` 并行。
- **页面与导航**：新增台上训练入口（首页卡片 + `/table` 相关路由），可能新增 `TablePlanPage` / `TableRunPage`；`src/App.tsx` 与 `Home.tsx` 增补入口。
- **持久化**：新增 `TableSession` 记录（台上训练课历史），复用既有 Repository/Zustand persist 模式，不迁移既有数据。
- **整合**：周末验证（`movementResult`）与 ONE CUE / limiter 结果被台上编排器读取，决定「今天上球台练什么」。
- **测试**：新增七层模型、生成公式、球源降难度、配比演进、自我教练闭环（五问/门槛/进阶/诊断）的领域单测；沿用 `pnpm verify` + Playwright 浏览器验证。
- **自检记录**：新增 `SelfCheckRecord`（六指标 + 最常见失误分类）与自检 store（`ttc:tableCheck`），驱动反馈递减与主注意点迁移。

> 本 change 交付物为规格、设计与任务分解；代码改动由后续 `/opsx:apply` 驱动的子 change 完成。
