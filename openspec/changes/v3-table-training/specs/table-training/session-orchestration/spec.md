# Spec Delta

## Purpose

定义一次台上训练课（90–120 分钟）的结构与训练配比，把有限台上时间分配到高价值的动作—步法—判断—前三板组合。

## ADDED Requirements

### Requirement: 90–120 分钟课表结构

系统 SHALL 提供 90–120 分钟台上训练课结构，依次为：身体+空挥热身、正反手基本球、当天核心动作、固定移动、半随机、发接发/前三板、随机/开放球、条件比赛/比赛。

#### Scenario: 课表按序排列

- **WHEN** 用户生成一次台上训练课
- **THEN** 课表按「热身 → 基本球 → 核心动作 → 固定移动 → 半随机 → 前三板 → 开放球 → 条件比赛」顺序排列，各段有建议时长

### Requirement: 训练配比

系统 SHALL 用「固定动作 / 固定脚步 / 半随机 / 发接发前三板 / 完全随机与比赛」五类配比描述训练构成。

#### Scenario: 配比可查看

- **WHEN** 用户查看训练课构成
- **THEN** 能看到五类训练各占的比例，且当前默认约为 30% / 25% / 20% / 15% / 10%

### Requirement: 高质量专项前置

系统 SHALL 将当天最重要、最需要动作质量的训练放在身体新鲜时，但 MUST 先经过热身 → 基本球 → 简单移动。

#### Scenario: 专项训练前置但先热身

- **WHEN** 用户当天有核心动作要修
- **THEN** 该核心动作被安排在热身与基本球之后，而非一上来就练

### Requirement: 每轮时间短

系统 SHALL 建议每轮约 3–6 分钟换人，而非单人连续 20 分钟。

#### Scenario: 短轮换保持质量

- **WHEN** 用户在训练课中
- **THEN** 每个训练块的时长建议为 3–6 分钟并提示换人

### Requirement: 配比随水平演进

系统 SHALL 使配比随动作稳定而演进：固定动作/脚步占比下降，随机/比赛占比上升，最终趋于 15% / 20% / 25% / 20% / 20%。

#### Scenario: 配比向识别—移动—决策—击球倾斜

- **WHEN** 用户动作越来越稳定
- **THEN** 系统推荐的配比逐步减少「练动作」、增加「识别—移动—决策—击球」
