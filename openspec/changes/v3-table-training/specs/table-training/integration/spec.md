# Spec Delta

## Purpose

定义台上训练编排器与既有离台训练系统的整合方式：台上练什么由离台数据决定，台上结果回填周末验证闭环，并遵守安全门。

## ADDED Requirements

### Requirement: 台上重点由离台数据决定

系统 SHALL 从离台训练的 ONE CUE 或 limiter 结果推导当天台上训练重点，而非让用户「想练什么就练什么」。

#### Scenario: 台上重点可推导

- **WHEN** 用户进入台上训练编排器
- **THEN** 系统根据当前 ONE CUE（如「身体先走」）或 limiter（如下肢稳定短板）推荐对应的台上训练重点（如固定移动、步法稳定）

### Requirement: 周末验证闭环

系统 SHALL 将台上训练结果与离台指标关联：周末球台验证（如移动迁移）回填到离台训练的趋势视图，用于判断离台训练是否迁移到球台。

#### Scenario: 离台指标对齐球台验证

- **WHEN** 用户完成周末球台验证
- **THEN** 验证结果（移动迁移）与离台训练指标出现在同一趋势视图，可判断迁移是否发生

### Requirement: 遵守安全门

台上训练（高强度）SHALL 遵守每日 Check-in 的安全门：Red 状态不生成台上训练课，Yellow 状态降低台上训练负荷。

#### Scenario: Red 不生成台上训练

- **WHEN** 用户当日 Check-in 为 Red
- **THEN** 系统不生成台上训练课，并提示先休息

### Requirement: 入口与导航

系统 SHALL 在首页提供台上训练入口，且该入口与既有「开始训练」（离台）并列、不冲突。

#### Scenario: 首页可进入台上训练

- **WHEN** 用户在首页
- **THEN** 能看到与「开始训练」（离台）并列的「台上训练」入口

### Requirement: 台上训练课持久化

系统 SHALL 持久化台上训练课记录（日期、目标技术、球源、套路段、完成情况），并可在数据页查看历史。

#### Scenario: 台上训练可追溯

- **WHEN** 用户完成一次台上训练课
- **THEN** 该课被持久化，之后可查看其日期、目标技术、球源与完成情况
