# Spec Delta

## Purpose

定义 L1–L7 各层的具体球路套路内容库，覆盖单技术、固定移动、固定组合、半随机、随机、发接发前三板与条件比赛，每条明确双方任务与升级条件。

## ADDED Requirements

### Requirement: 内容库覆盖七层

内容库 SHALL 至少覆盖 L1–L7 每一层，且每层至少有一条可执行的球路套路。

#### Scenario: 每层有可用套路

- **WHEN** 用户浏览内容库
- **THEN** L1 到 L7 每一层都有至少一条球路套路可选用

### Requirement: 每条含双方任务

每条套路 MUST 明确 A 方与 B 方各自的任务，贯彻「一颗球两个人同时训练」，不允许出现「A 训练、B 挡球」的单方任务。

#### Scenario: 双方都有训练任务

- **WHEN** 用户查看任意一条套路
- **THEN** 能看到 A 方与 B 方各自明确的训练任务（如 A 正手三点移动、B 反手挡球落点控制）

### Requirement: 单技术层套路（L1）

L1 MUST 覆盖正手对攻、反手对攻、正手直线、反手直线、正手拉上旋、反手拉上旋、正手起下旋、反手起下旋等基础单技术。

#### Scenario: 单技术基础覆盖

- **WHEN** 用户在 L1 选择单技术训练
- **THEN** 能看到正手/反手对攻、直线、拉上旋、起下旋等基础球路

### Requirement: 固定移动层套路（L2/L3）

固定移动与固定组合套路 MUST 覆盖两点正手、正反手转换、Falkenberg，以及「反手 2 板 → 正手 2 板」「反手 → 中路正手 → 反手 → 大正手」「正手斜线 2 板 → 正手直线 2 板」等组合。

#### Scenario: 脚步与组合套路可用

- **WHEN** 用户选择固定移动或固定组合训练
- **THEN** 能看到两点正手、正反手转换、Falkenberg 及正反手/落点组合套路

### Requirement: 半随机与随机层套路（L4/L5）

L4 半随机 MUST 至少覆盖「第一球固定、第二球随机」的套路；L5 随机 MUST 至少覆盖「A 方全台移动、B 方反手控制三点」的双向训练套路。

#### Scenario: 判断与反应层覆盖

- **WHEN** 用户进入 L4 或 L5
- **THEN** 能看到半随机（第一球固定、第二球随机）与随机（一方全台移动、另一方控制落点）的套路

### Requirement: 发接发前三板层套路（L6）

L6 MUST 覆盖发抢的进阶：发下旋 → 搓长反手 → 反手起板；发下旋 → 搓长正手/反手二选一 → 判断后起板；发短球 → 摆短/劈长 → 短球控制或长球起板。

#### Scenario: 前三板衔接覆盖

- **WHEN** 用户进入 L6 训练
- **THEN** 能看到从「搓长 → 起板 → 连续」的完整发抢套路，而非直接「摆短 → 暴拧 → 反撕」

### Requirement: 条件比赛层套路（L7）

L7 MUST 提供条件局规则（如「发下旋必须第三板起球」「接发只许搓长」「反手起板成功得 2 分」「第一板必须攻击肘部」），用于把当天训练技术迁移到比赛。

#### Scenario: 条件比赛检验迁移

- **WHEN** 用户进入 L7
- **THEN** 能选择一条强制使用当天技术（如反手起板）的条件局规则

### Requirement: 三点落点非左中右

三点落点 SHALL 指「大正手 / 追身（肘部）/ 大反手」，而非「左 / 中 / 右」。

#### Scenario: 三点定义正确

- **WHEN** 套路涉及三点落点
- **THEN** 三个落点为 大正手、追身（肘部）、大反手，中路球被识别为更难处理的位置

### Requirement: 每条套路遵循统一模板

内容库每条套路 MUST 按统一模板填写：训练方法 → 唯一注意点 → 正确体感 → 常见错误体感 → 自检指标 → 进阶阈值 → 保持测试 → 迁移测试 → 下一级训练。

#### Scenario: 模板保证可自验

- **WHEN** 用户查看内容库任意一条套路
- **THEN** 能看到该套路按「训练方法→唯一注意点→正确体感→常见错误体感→自检指标→进阶阈值→保持测试→迁移测试→下一级训练」填写完整
