# Spec Delta

## Purpose

定义训练套路数据模型（Drill）与训练生成公式，把「谁打什么球 → 打到哪里 → 对方怎么回 → 我接下来干什么」固化为可计算、可生成、可进阶的资源。

## ADDED Requirements

### Requirement: Drill 八要素

每个训练套路 MUST 包含：目标技术、球源、规则、随机度、训练者关注点、搭档任务、升级条件、下一等级。

#### Scenario: 套路完整可执行

- **WHEN** 用户打开一个训练套路
- **THEN** 能看到目标技术、球源、规则、随机度、训练者关注点、搭档任务、升级条件与下一等级，足以据此开始训练

### Requirement: 训练生成公式六维度

系统 SHALL 用「技术 × 落点 × 移动 × 旋转 × 随机度 × 前后板」六个维度描述并生成训练套路，使任意技术都能组合出训练变体。

#### Scenario: 从目标技术生成训练变体

- **WHEN** 用户指定一个目标技术（如反手起下旋）
- **THEN** 系统能沿六个维度生成从固定到随机的训练变体（如固定反手下旋 → 反手两落点 → 正反手下旋随机 → 发球后反手起）

### Requirement: 规则描述四段式

套路的规则 SHALL 明确「谁打什么球 → 打到哪里 → 对方怎么回 → 我接下来干什么」，而非仅描述为「正手攻球 5 分钟」。

#### Scenario: 规则约束球路

- **WHEN** 用户查看套路规则
- **THEN** 规则明确到每个回合的发球/回球/落点与下一板，双方都清楚自己该打什么球

### Requirement: 随机度分级

随机度 SHALL 分为「固定 / 半随机 / 随机」三级：固定即完全知道下一球，半随机即部分知道，随机即不知道。

#### Scenario: 随机度可区分

- **WHEN** 一个套路的随机度被设定
- **THEN** 它只能是固定、半随机、随机之一，且对应「知道 / 部分知道 / 不知道」下一球

### Requirement: 升级条件与下一等级

每个套路 MUST 附带升级条件（如「连续 20 板 × 3 组」）与下一等级的链接，用于判断何时进入更难一级。

#### Scenario: 满足升级条件进入下一等级

- **WHEN** 用户满足某套路的升级条件
- **THEN** 系统引导其进入「下一等级」所指的更难套路

### Requirement: Drill 与自我教练闭环关联

每个 Drill 的「训练者关注点」SHALL 是唯一主注意点，「升级条件」SHALL 由四道进阶门槛定义，「下一等级」SHALL 指向进阶算法（Level A–G）的下一级。

#### Scenario: 套路内嵌自检闭环

- **WHEN** 用户打开一个套路
- **THEN** 该套路的关注点只有一个主注意点，升级条件引用四道进阶门槛，下一等级指向进阶算法下一级
