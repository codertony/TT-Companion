# Spec Delta

## Purpose

定义台上训练的七层进阶模型（L1 单技术 → L7 条件比赛）与进阶链，作为台上训练编排的分类骨架和随机度演进依据。

## ADDED Requirements

### Requirement: 七层进阶模型

系统 SHALL 将台上训练分为七层：L1 单技术、L2 固定落点、L3 固定移动、L4 半随机、L5 随机、L6 发接发与前三板、L7 条件比赛。

#### Scenario: 按七层分类任意台上训练

- **WHEN** 一个台上训练套路被归类
- **THEN** 它被归入七层之一，且每层有明确的「是否知道下一球」与「主要目的」

### Requirement: 每层三要素

每一层 MUST 明确标注「是否知道下一球」（知道 / 部分知道 / 不知道）、「主要目的」与「核心训练」，用于区分层的难度与训练意图。

#### Scenario: 层三要素可解释

- **WHEN** 用户查看某一层的定义
- **THEN** 能看到该层「是否知道下一球」「主要目的」「核心训练」三项，且 L1/L2/L3 为「知道」、L4/L6 为「部分知道」、L5/L7 为「不知道」

### Requirement: 进阶链顺序

系统 SHALL 按「固定球路建立动作 → 固定移动建立脚步 → 半随机加入判断 → 发接发加入前三板 → 开放球路接近实战 → 比赛检验」组织进阶，不允许跳过中间层直接开放随机。

#### Scenario: 进阶遵循固定到开放

- **WHEN** 系统为一个目标技术生成进阶链
- **THEN** 链上的训练按「固定 → 半随机 → 随机 → 比赛」递增开放度，而不是从随机开始

### Requirement: 固定与随机的配比演进

系统 SHALL 使随机训练占比随用户水平提升逐渐增加，避免「练球漂亮、比赛不会打」。

#### Scenario: 随水平上调随机比例

- **WHEN** 用户的动作稳定性提升
- **THEN** 系统推荐的训练配比中，随机/比赛情境训练的占比单调不降，固定动作占比单调不升

### Requirement: 稳定性优先于力量

系统 SHALL 以「稳定性 → 落点 → 节奏 → 速度 → 力量」为进阶顺序，在动作稳定前不增加速度与力量。

#### Scenario: 动作不稳时优先降速

- **WHEN** 用户连续掉球、动作尚未稳定
- **THEN** 系统建议降低速度与力量、减少落点变化，而非要求更用力
